# Akash Reddy Vangala — Portfolio

Responsive portfolio built with React, Vite, and Lucide icons. Includes Home, About, Skills, Projects, Education, Certifications and Contact sections.

## Run locally

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Use framework preset **Vite**, build command `npm run build`, output directory `dist`.
4. Deploy.

## Add your resume

Place your PDF resume at `public/resume.pdf` (replace the placeholder instructions file). The Resume navigation link points to `/resume.pdf`.

## Customize

Edit `profile`, `projects`, and `skillGroups` at the top of `src.jsx` to change the content. The contact action uses a `mailto:` link rather than a form backend.

No photo was added because no portrait was supplied. No employment experience section was added because professional software-engineering employment was not verified. Add it when appropriate.
